# ExpenseTracker-main

A modern, full-stack Expense Tracker web application designed to help users manage their personal finances efficiently. It provides an easy-to-use interface for recording expenses, monitoring spending habits, and organizing financial transactions.

Built using the MERN stack, this project demonstrates full-stack development, REST API integration, database management, and responsive UI development.

🚀 Features

📊 Dashboard: Get an overview of your financial activities.

💸 Expense Management: Add, view, update, and delete expenses.

📁 Category Management: Organize expenses into different categories.

📈 Expense Monitoring: Track spending and understand financial patterns.

🎨 Modern UI: Clean and user-friendly interface.

📱 Responsive Design: Accessible across different screen sizes.

⚡ REST API Integration: Connect frontend and backend seamlessly.

🗄️ Database Management: Store and manage financial records.

⚙️ Installation and Setup

1. Clone the Repository

git clone https://github.com/SANJAYKUMAR-2006/ExpenseTracker-main.git

2. Navigate to the Project

cd ExpenseTracker-main

3. Backend Setup

cd backend
npm install

Create a .env file inside the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string

Start the backend server:

npm run dev

4. Frontend Setup

Open another terminal:

cd frontend/expense-tracker
npm install

Start the React development server:

npm run dev

5. Access the Application

Open the local URL displayed by Vite, usually:

http://localhost:5173
